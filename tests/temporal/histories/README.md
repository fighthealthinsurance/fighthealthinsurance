# Recorded workflow histories

Every `*.json` here is replayed against the current workflow code on each CI
run by `../test_workflow_replay.py`.

## Why

`IntakeJourneyWorkflow` runs for **30 days**. A workflow-code change deployed
inside that window is replayed against histories written by the old code. If
the change alters the sequence of commands the workflow issues, in-flight runs
fail with a non-determinism error — not at deploy time, but later and one at a
time, on workflows a patient is waiting on.

Replaying a fixed history in CI turns that into a failed build instead.

## The baseline

`intake_journey_completed.json` is generated by the test environment (stub
child workflow, stub activities) and covers the completion path: start →
`form_completed` signal → child generation → close.

It is a **floor, not full coverage**. A real production history exercising a
nudge or a reconciliation is strictly better — add one when you have it.

## Capturing a production history

```sh
kubectl -n totallylegitco exec deploy/temporal-admintools -- \
  temporal workflow show \
    --address temporal-frontend:7233 --namespace default \
    --workflow-id <workflow-id> --output json \
  > tests/temporal/histories/<name>.json
```

Prefer histories that exercised different paths. One of each shape beats ten
of the same.

## Before committing one

`TEMPORAL_PAYLOAD_KEY` is unset in production, so payloads are **plaintext in
the JSON**. The journey's inputs are ids-only by design (`hashed_email`,
`denial_uuid`, `contact_opt_in`), but read the file before committing and
confirm nothing else rode along. If payload encryption is later enabled, a
captured history needs the codec configured to replay.

## Regenerating the baseline

```sh
FHI_CAPTURE_HISTORY=1 tox -e py313-django52-temporal -- \
    tests/temporal/test_workflow_replay.py -k capture_baseline
```

Only when a workflow change is intentional and the new command sequence has
been reviewed. Overwriting the baseline is how you tell CI "this drift is
expected" — doing it reflexively defeats the gate.
