3. Models

This is the setup HumanJudge's arena docs call "Answers you already have": every model below is registered as its own HumanJudge model, all pointing at our one endpoint, with the model named in its request template. For each model, in Developer Hub:

  1. Create a model. Its name is what the arena's public leaderboard shows; verdicts are matched by the answer's text, not by this name.
  2. On its Setup tab, under Endpoint Configuration, fill in all four fields:
    • Endpoint URL: {{ endpoint_url }}
    • API Key: the value of HUMAN_JUDGE_OAI_CALLBACK
    • Request template: the one listed beside the model below. Replace what the form starts with: it names gpt-4o, which our endpoint refuses as an unknown model.
    • Response path: {{ response_path }} (what the form starts with)
  3. Click Save endpoint. Test endpoint does not save, and a model without a saved endpoint is skipped when the arena generates.
  4. Click Test endpoint. It sends "Say hello in one sentence." and should show Response: "…" with the model's one-line reply (one real call to the model). "Invalid API key" means the key is wrong; "No arena model named…" means the request template's model is not one below.
  5. On the model's page, open Enter a Challenge and enter the arena; back on the arena's page, approve it with the ✓ next to its name.
