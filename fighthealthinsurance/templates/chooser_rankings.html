How this is counted

  • Win rate is votes a model's draft won over votes it was shown in. A referee who finds two or more drafts equally good can call a tie, which splits that vote evenly between them (half a win each for a two-way tie). Drafts are shown blind (the page gets opaque references, never a model name or a stored order), in random order, so a vote is for the letter, not the brand. Only votes cast since blind voting began count.
  • Caught making things up is how often a referee flagged the draft for inventing a study, a law, a test result, a date or a history that was not in the case. A draft can be flagged and still lose honestly; a flagged draft can never be the vote.
  • Warming up marks a model with fewer than {{ data.min_shown }} votes; its rates are listed but not ranked against the rest.
  • Cases are synthetic. Each one is written by a model about a real condition and treatment pair, with made-up facts and the published evidence already on file for that pair. Newer cases also carry a summary of each study and the made-up patient's answers to the questions the app would ask, and every draft is given the same. No real patient's letter is ever shown.
  • The same data is available as JSON. Counts refresh every few minutes.
