{% comment %} The file button inside a letter's text box (.fhi-letter-box in custom.css). It goes straight after the box's textarea, in the .fhi-letter-box that holds both and carries data-file-drop, so a file dropped anywhere on the box goes to the same input (file_drop.js). Empty, the box shows the button in its middle with the other ways in under it; with text in it, the button sits at its foot and adds another page. The input DELIBERATELY has no name= attribute. The browser only includes a file input in the multipart body when it has a name, and these pages read the letter on this device: with a name, every letter a person attached would be uploaded and buffered by the server for nothing, an unnecessary disclosure of the exact document these pages keep in the browser. The pages' scripts find it by id. Do not add a name back without also changing what the pages promise about the file. accept: the file types the picker offers, if limited. note: what the page does with the file, read with the button. {% endcomment %}
